# BLQS Progress Monitor

แดชบอร์ด static สำหรับ GitHub Pages แสดงเวลาและความคืบหน้าการแก้ไข NC ของคำขอ MG 211/69

## ใช้งาน

บน Windows ให้ดับเบิลคลิก `เปิดแดชบอร์ด.bat` แล้วเปิด `http://localhost:9010` ในเบราว์เซอร์ หน้าต่างคำสั่งต้องเปิดค้างไว้ระหว่างใช้งาน และปิดหน้าต่างนั้นเมื่อต้องการหยุดระบบ

หรือเผยแพร่เนื้อหาในโฟลเดอร์นี้บน GitHub Pages

การอัปเดตข้อมูลให้แก้ไข `data/status.json` แล้ว push ขึ้น GitHub หน้าเว็บจะดึงไฟล์ใหม่ทุก 60 วินาที

สถานะที่รองรับคือ `รอการบันทึกแก้ไข`, `อยู่ระหว่างประเมินการแก้ไข`, และ `ผ่านการประเมินแล้ว`

ค่าเริ่มต้น `dueDate` คือ 30 วันหลังสิ้นสุดการตรวจประเมิน หากวันกำหนดส่งจริงต่างจากนี้ให้แก้ในไฟล์ JSON แล้ว push ขึ้น GitHub เพื่อให้ทุกคนเห็นค่าเดียวกัน
